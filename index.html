Downloader code for the Firestick: how to set it up (2026)

✍️ Charlotte Barnes · 📅 October 2026 · ⏱️ 4 min read · 🛡️ Verified Review

You need the Downloader app and a download code from your streaming provider to install third-party apps on your Firestick. This guide shows you the exact steps to set it up in 2026.

You will also learn how to use it with a premium subscription like SubTV IP.

What you need before you start

  • A Fire TV Stick (any model) connected to Wi‑Fi
  • The Downloader app (free from the Amazon Appstore)
  • A download code (short URL or numeric code) from your streaming service – for example, SubTV IP provides one after you buy a subscription
  • Your Firestick remote control

Step-by-step setup

  1. From the Firestick home screen, go to “Settings > My Fire TV > Developer Options”. If you don’t see “Developer Options”, go to “Settings > My Fire TV > About” and press the center button on “Fire TV Stick” seven times to unlock it. Then back to Developer Options.
  2. Inside Developer Options, turn on “Apps from Unknown Sources” (or “Install unknown apps”). This lets you install apps outside the Amazon store.
  3. Go back to the home screen. Use the search icon and type “Downloader”. Select the app by AFTVnews LLC and click “Get” or “Install”.
  4. Open Downloader. Accept the terms and conditions when asked.
  5. In Downloader, you will see a URL bar. Type the download code from your provider. For example, if you are a SubTV IP subscriber, enter the code they gave you inside your welcome email. Then click “Go”.
  6. Downloader will now fetch a file (usually an .apk file). Wait for the download to complete. It usually takes less than 30 seconds.
  7. When the download finishes, a pop‑up will ask “Install this app?”. Click “Install”. Then click “Done” and “Delete” the downloaded file to save space.
  8. Return to the Firestick home screen. The newly installed app (e.g., the SubTV IP player) will appear in “Your Apps & Channels”. Open it and log in with the username and password from your subscription.

If a step fails – common fixes

“Apps from Unknown Sources” is grayed out. Make sure you are connected to the internet. Restart your Firestick by unplugging it for 10 seconds.

The download code doesn’t work. Double‑check the code. Sometimes providers give a short URL like “bit.ly/xyz ” – type it exactly. If it still fails, contact your provider’s support (SubTV IP offers WhatsApp support).

Downloader says “Download unsuccessful”. Your internet may be too slow. Try switching to a wired connection or move the Firestick closer to the router. You can also change your DNS to Cloudflare (1.1.1.1) in “Settings > Network > Your Wi‑Fi > Advanced”.

The app won’t install. Go to “Settings > Applications > Manage Installed Applications” and clear cache of Downloader. Then try again.

Frequently Asked Questions

What is the Downloader app on Firestick?

Downloader is a free app that lets you download files and install third‑party apps on your Fire TV Stick. You enter a code or URL, and it fetches the file for you.

Is Downloader free?

Yes, the Downloader app is completely free. You download it from the Amazon Appstore. There are no hidden charges.

How do I enable unknown sources on Firestick?

Go to “Settings > My Fire TV > Developer Options > Apps from Unknown Sources” and turn it on. If you don’t see Developer Options, go to “About” and press the center button seven times on “Fire TV Stick”.

What code do I need to enter in Downloader?

You need the download code provided by your streaming service. For example, after buying a subscription from SubTV IP, they give you a short code inside your confirmation email. That code points to their app or player.

Can I use Downloader to install any app?

Yes, as long as you have the correct download URL or code for the app’s APK file. Downloader works for many Android apps, not just streaming ones.

Is SubTV IP safe to use on Firestick?

SubTV IP is a paid premium subscription with secure payment options like PayPal and credit card. It uses Cloudflare DNS to prevent ISP throttling and supports anti‑freeze server clusters. Always buy from the official website subtvip.store.

How do I update the Downloader app?

Amazon usually updates Downloader automatically. You can also check for updates by going to “Settings > Applications > Manage Installed Applications > Downloader” and selecting “Check for updates”.
